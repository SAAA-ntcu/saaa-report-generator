# SAAA Full Report Architecture & Pipeline Reference

本手冊說明國中小學生學習能力檢測結案報告全七章（Chapters 1~7）的自動化管線架構與模組設計。

---

## 1. 架構原則：模組解耦、管線融合

本系統採用「**模組獨立實現、管線統一調度、母體精準縫合**」的微內核架構（Pipeline Architecture）：

```text
SAAA-Report-Engine (統一調度)
│
├── 1. 核心章節生成模組 (scripts/modules/)
│   ├── ch1_2_admin.py        # 壹、背景與目的 + 貳、參與縣市與檢測規模 (表2-1)
│   ├── ch3_framework.py      # 參、檢測對象與檢測工具 (表3-1)
│   ├── ch4 (generate_reports)# 肆、試題分析與教學建議 (含題本截圖、去題號、24pt行高)
│   ├── ch5_performance.py    # 伍、整體學力表現分析 (圖5-1、表5-1-x 課綱PDF即時抽取)
│   ├── ch6 (generate_reports)# 陸、整體教學建議 (表6-1 通過率交叉矩陣)
│   └── ch7_appendix.py       # 柒、附錄 (題本、答案、疑義公告)
│
├── 2. 總裝與縫合引擎 (docx_assembler.py)
│   ├── 支援以 114 範本為基底，抽換或注入指定章節
│   ├── 支援從零建立標準骨架 (Cover、目錄、分節、頁碼)
│   ├── 全文統一微軟正黑體、清除遺留書籤
│   └── 調用 proper_names.py 注入專名號單底線
│
└── 3. 全方位品質檢驗 (qa_verify.py)
    ├── 第一章：18縣市聯集與年度型新增自然科最新規範文案
    ├── 第二章：表2-1 縣市到考統計與總計核對
    ├── 第三章：檢測對象統計與表3-1向度分布題數
    ├── 第四章：試題題數、信度、題目圖片SHA256、24pt固定行高
    ├── 第五章：圖5-1學力分布圖與表5-1-x十區間交叉表
    ├── 第六章：表6-1向度矩陣與通過率精確度
    └── 第七章：附錄節點與完整度檢驗
```

## 2. 第一章背景最新規範：年度型新增自然科

依據最新年度型學力檢測規範（新增自然科學領域），第一章第二段結尾統一採用以下標準文案：

> **「107 年開始，<u>桃園市</u>等五縣市以委託形式，由<u>國立臺中教育大學測驗統計與適性學習研究中心</u>協助辦理縣市學生學習能力檢測試題研發暨資料分析工作，108 年起，改以中心自辦學力檢測研發，各縣市依需求參與形式運作，115 年度有<u>基隆市</u>、<u>新北市</u>、<u>桃園市</u>、<u>新竹縣</u>、<u>新竹市</u>、<u>苗栗縣</u>、<u>臺中市</u>、<u>南投縣</u>、<u>雲林縣</u>、<u>嘉義縣</u>、<u>嘉義市</u>、<u>臺南市</u>、<u>高雄市</u>、<u>屏東縣</u>、<u>花蓮縣</u>、<u>臺東縣</u>、<u>澎湖縣</u>以及<u>金門縣</u>等十八縣市共同參與，檢測對象為國民中小學三年級至八年級學生，<u>檢測科目包含國語文、數學、英語文和自然。</u>」**

### 格式要求：
1. **年級文字**：由舊版「三至八年級」改為標準公文全稱「**三年級至八年級**」。
2. **科目文字**：由「國語文、數學和英語文」更新為「**國語文、數學、英語文和自然**」。
3. **專名號**：中心全稱「國立臺中教育大學測驗統計與適性學習研究中心」與全部 18 個縣市名稱，均需標註單底線（`w:u val="single"`）。

## 3. 三種操作模式

### 模式一：一鍵全書總裝（Full Assembly）
```bash
python scripts/build_full_report.py \
  --subject M \
  --grade 4 \
  --year 115 \
  --chapters all \
  --out-dir "結案報告輸出"
```

### 模式二：階段性產出（專家填寫版 / 行政審查版）
```bash
# 產出第一、二章（行政與人數規模）：
python scripts/build_full_report.py --subject C --grade 3 --chapters 1,2 --out-dir "行政輸出"

# 產出第四、六章（送交領域輔導團專家撰寫教學建議）：
python scripts/build_full_report.py --subject E --grade 7N --chapters 4,6 --booklet-pdf "英語題本.pdf" --out-dir "專家審查"

# 產出第五章（學力統計圖表與課綱條目交叉表）：
python scripts/build_full_report.py --subject S --grade 5 --chapters 5 --curriculum-pdf "自然科學領域.pdf" --out-dir "學力輸出"
```

### 模式三：自動化品質稽核（QA Audit）
```bash
python scripts/qa_verify.py --dir "結案報告輸出"
```
自動逐章驗證：
- 是否具備第一章最新自然科文案
- 專名號單底線數量
- 表 2-1 與表 3-1 結構
- 全文字型是否嚴格統一為微軟正黑體
- 是否存在黑色方點或 XML 斷頁異常

## 5. 第七章（柒、附錄）排版與題本渲染規範

第七章收錄正式測驗題本與附錄參考資料，其排版嚴格遵循官方成果報告規範：
1. **章節標題 `柒、附錄`**：
   - 底色填滿：`w:shd w:val="clear" w:color="auto" w:fill="DDEBF7"`
   - 行距規範：固定行高 24pt (`w:spacing w:line="480" w:lineRule="exact"`)
   - 段落對齊：置中對齊 (`w:jc w:val="center"`)
   - 字型規範：微軟正黑體 12pt 粗體 (`w:sz w:val="24"`, `w:b`)
2. **題本高解析度渲染**：
   - 採用 PyMuPDF (`pymupdf`) 逐頁向量渲染至 181.4068 DPI，產生寬度 1500px 之高畫質 PNG，確保試題圖文、數學符號、英文長篇閱讀極致清晰。
   - 圖片尺寸設定：寬度 489.0 pt (`6,210,300 EMU`)、高度 691.8 pt (`8,785,504 EMU`)，完美符合標準 A4 邊距。
3. **換頁與段落控制**：
   - 第一頁題本圖片緊隨於章標題後，設定 `<w:pageBreakBefore w:val="0"/>`。
   - 第二頁至最後一頁題本圖片段落強制設定 `<w:pageBreakBefore/>`，確保每一頁試題皆獨立滿版呈現，無多餘空行。
4. **標準版面邊界**：
   - 上邊界：`64.8 pt` (0.9 in)
   - 下邊界：`50.4 pt` (0.7 in)
   - 左邊界：`56.7 pt` (0.787 in)
   - 右邊界：`49.6 pt` (0.689 in)
